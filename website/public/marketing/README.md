# Landing-page imagery

`shop-owner.webp` is an AI-generated illustrative marketing photograph, created with the built-in image-generation tool. It does not depict or endorse a named customer. The selected generated image was copied into the project and encoded as WebP for the website.

Generation prompt: Photorealistic editorial portrait of a smiling Black Rwandan woman entrepreneur with braided hair, an emerald-green apron over a black shirt, using a tablet in a bright grocery/cafe shop. Natural daylight, realistic skin and hands, softly blurred shelves and plants, cream and sage background, no text, logos or interface overlays. The website interface is implemented separately in code.
