TwemojiCountryFlags.woff2 is the country-flag subset of Mozilla's Twemoji
color font, distributed by country-flag-emoji-polyfill v0.1.8:
https://github.com/talkjs/country-flag-emoji-polyfill

Emoji artwork: Twemoji, licensed under CC BY 4.0.
Font source: https://github.com/mozilla/twemoji-colr
License: ./TwemojiCountryFlags.LICENSE.md

The upstream subset is bundled unchanged. The application uses it only for
Unicode regional indicators, enabling country flags in Windows Chrome.
