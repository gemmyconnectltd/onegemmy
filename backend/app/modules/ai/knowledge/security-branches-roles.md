# Security, branches and roles
Every business's data is isolated to its own account and encrypted in transit. You can export your data at any time. Add as many branches as you need; every sale and employee is tagged to a branch and you can switch branch from the top bar. Stock transfers between branches are logged.

Roles and permissions control what each person sees and can do: for example a cashier and an accountant see different things, and each permission is a resource and an action (such as orders: read, or stock: update). Manage users and roles under Settings > Users. Pesaa AI applies the same rules: it only answers from data the signed-in person is allowed to see, within their branch.
