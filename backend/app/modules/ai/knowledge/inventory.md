# Inventory
Inventory tracks stock per product, per warehouse/branch. Every sale, purchase receipt and return moves the same number, so the count on screen matches the shelf.

- Low-stock alerts warn you before you run out, based on each product's minimum stock.
- Restock adds units to a product; Adjust sets the stock to a counted number (for example after a stocktake or damage).
- Variants (size/colour), batches with expiry dates and serial numbers are supported.
- Stock transfers log stock moving between branches.
- Suppliers can have a lead time (days from ordering to delivery); Pesaa AI uses it so reorder advice covers the wait.
- Products can be imported in bulk from CSV/Excel.

To see what to reorder, ask Pesaa AI "Which products should I reorder?". It compares stock with recent sales speed and shows how each number was worked out.
